# hugo-theme-pebble

Pebble is a Hugo theme for product showcase websites.

## Included

- `layouts/`
- `static/app.js`
- `static/styles.css`
- `exampleSite/`

## Example Site

Pebble includes a runnable example site under `exampleSite/` with:

- multilingual content
- config defaults
- i18n messages
- sample product assets

Run it from the theme repository root:

```bash
cd exampleSite
npm run dev
```

Or without npm:

```bash
hugo server --source exampleSite
```

Site-specific content, translations, assets, and configuration should live in the consuming Hugo site.
